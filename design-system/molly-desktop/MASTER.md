# MollyCloud 桌面端设计规范

版本：2026-10-02 · 官网视觉统一版

适用范围：登录、两步验证、协议、概览（账户概览 / 订阅 / 用量 / 充值）、API 密钥、Molly助手、CC Switch、灵动岛、生图工作台、Skill 管理器。2026-10-02 按用户提供的官网截图统一为荧光绿与中性灰配色，订阅和用量归入概览二级菜单，移除独立 MCP 市场。页面细则不能覆盖公共框架。CC Switch 和生图工作台的原版 UI 例外仅限各自的内嵌内容区；充值采用 Molly 原生界面，仅支付验证页使用隔离 WebView。本文后半部注明日期的回归记录保留当时状态，不代表当前导航和功能。

## 1. 设计目标与实现入口

### macOS 平台约定（2026-10-03）

macOS 版按用户要求移除 NetSpeed Dynamic：主导航为概览、CC Switch、Molly助手、生图工作台、Skill 管理器五项，不创建灵动岛窗口或打包其辅助程序。其余公共导航、标题栏、字体 token、工作区背景及 Petra 独立透明布局继续复用本规范。平台文案使用“macOS 钥匙串”“菜单栏”和“登录 macOS 后自动启动”；自动登录保存在系统钥匙串，助手密钥使用钥匙串保护的本机加密存储。系统音频响应默认关闭，用户开启后才请求 ScreenCaptureKit 权限；已有明确保存的开启选择可恢复。UI 回归在 macOS 使用独立临时 Chrome / Edge 配置，覆盖登录、五项导航及全部子页的三种窗口尺寸，Windows 继续覆盖六项导航。

2026-10-04：API 密钥管理统一到 CC Switch，删除独立导航项；概览中的密钥数量跳转 CC Switch。Official 和手动供应商卡片沿用内嵌 UI，账户密钥列表放在供应商卡片下方；创建、删除、分组和模型配置弹窗复用 Molly 公共组件、主题及模态层，不增加页面专属公共框架覆盖。首次未配置的官方工具选择空白 Official；重复同步保留用户选择，多供应商工具等待手动添加。 两种主题各 84 组回归通过，覆盖三种尺寸，失败及运行时异常为空；已查看统一密钥列表及分组弹窗截图，证据在 `artifacts/design-review/`。

macOS 前端回归：86 项前端 / 6 项脚本测试、CC Switch 16 项嵌入测试、完整生产构建和 public 179 / dist 192 文件资源检查通过。深浅色各 84 组界面检查覆盖登录、六项入口和子页、960×640 / 1180×760 / 1440×900，失败和运行时异常均为空；已查看登录、六项入口和多种尺寸的截图。证据位于 `artifacts/design-review/{light,dark}/`。Windows 独立前端构建保留灵动岛入口与组件，Mac 产物确认无灵动岛 HTML、动态组件、原生 IPC 命名空间或 EXE。此记录只描述前端和资源验证，不替代原生、真实 API、支付或发行验收。

macOS 控制台采用系统装饰窗口与 Overlay 标题栏，由系统提供圆角外框、外部阴影和真实红黄绿按钮，隐藏窗口标题。共享标题栏高 44px，原生按钮位于左侧，菜单栏切换按钮左距 92px、上距 6px，置于绿色按钮右侧；不绘制 HTML 窗口控制。原生关闭继续遵循控制台关闭策略。Windows 保留 32px 自绘标题栏。此差异对登录及全部控制台页面统一生效，不影响 Petra 独立透明窗口。

浅色界面使用连续的浅灰标题栏与侧栏外框、白色工作区及表面、深灰文字和荧光绿交互强调；深色界面使用较深的炭灰外框与稍亮的内容表面、浅色文字及相同的荧光绿强调。两种主题共用布局、字体与组件规则。数据优先，装饰服务于分组，页面切换时公共界面保持稳定。

组件主题读取 CSS token 并转为颜色字面值。Naive UI 会在 JavaScript 内计算派生颜色，不能把 `var(--color-…)` 直接传入需要颜色运算的主题字段。

关闭 Naive UI 默认 preflight，由公共 CSS 管理文档字体；不能仅设置 `common.fontFamily` 后假定正文已同步。开发和生产入口都要检查实际计算字体。

使用规则：

- 主按钮配深绿色文字，不能用白字叠在浅绿底上。辅助文字不能直接使用亮绿色。
- 选中导航通过荧光绿整块背景、深色文字和深色图标表示，不依赖贴边色条。
- 普通卡片四边使用同一中性颜色。语义色放在图标、数字、状态标签或容器内部的有界区域。订阅卡片按用户要求同步官网，允许使用供应商浅色四边框；此例外不延伸到公共外框或其他卡片。
- 余额和订阅到期提示属于同一种账户提醒，使用相同浅绿表面；错误提示使用错误色。
- 不为某个菜单页面重新定义背景色、导航字体或主题色。
- 控制台输入光标始终为黑色 `--color-input-caret: #000000`，深色主题也不覆盖；Naive UI 与内嵌工具共用此规则。仅导入输入光标样式不改变生图 sandbox 的隔离权限。

### 深色与系统外观

默认选择“跟随系统”，实时响应系统浅色/深色变化；用户指定浅色或深色后不再受系统变化影响。共享 token 通过根节点 `data-theme` 切换，Naive UI 同步切换基础主题并重新读取颜色字面量。登录、两步验证、协议、全部控制台页面、下拉选单和各设置弹层一并变化。Petra 透明窗口不接入控制台主题。

深色核心值为工作区与卡片 `#22251f`、标题栏与侧栏外框 `#191b18`、次级表面 `#2a2d26`、主文字 `#eef1e9`、次文字 `#bec4b6`、边框 `#383d32`；主按钮继续使用 `#b5ff36` 与 `#233600` 文字。全部颜色由共享 token 文件维护。

侧栏底部仅保留设置按钮，不再提供独立太阳/月亮主题切换按钮；紧凑侧栏中设置图标与导航图标保持统一尺寸和对齐。设置弹层的“外观”提供“跟随系统 / 浅色 / 深色”原生单选组，遵守草稿、取消与保存规则。偏好保存在当前应用来源的 `mollycloud:appearance`；设计预览使用独立的 `mollycloud:preview:appearance`，不写桌面偏好。写入失败保留当前主题并显示错误。

生图工作台复用原版媒体查询深色样式，通过 iframe 继承的 `color-scheme` 跟随宿主，保留原有 sandbox 与 MessageChannel 边界。CC Switch 复用原版深色 class 和组件主题，在现有同源嵌入边界内监听宿主 `data-theme`；内嵌设置提示外观由控制台管理，不写独立版或内置旧主题偏好、不设置原生窗口主题。主题切换不能重载 iframe 或丢失编辑状态。

### 字体与文字层级

正文统一使用 `--font-body`：Segoe UI Variable Text → Segoe UI → Microsoft YaHei UI → PingFang SC → sans-serif。中文和英文均保持无衬线外观，不加载独立的页面字体。

| 内容 | 规范 |
| --- | --- |
| 登录标题 | 32–42px，700 |
| 控制台页级标题、问候与介绍 | 不显示；当前页面由主导航、二级菜单的选中项表达 |
| 导航文字 | 14px，500；选中项 600 |
| 内容标题 | 普通分组 15–17px；用量构成与聊天工具栏 20–22px |
| 表单、表格、说明 | 13–16px，依信息密度选择 |
| 关键统计数字 | 概览 19–24px；累计用量 22–32px；等宽数字特性 |
| 密钥、API 端点、验证码 | `--font-mono`，Fira Code / Cascadia Mono / Consolas |

金额和统计值以正文字体配 `font-variant-numeric: tabular-nums` 为主。金额精度和币种由业务格式化函数控制，不能为排版修改金额含义。长消息允许换行；单行名称可以省略，但不能挤占操作按钮。

## 3. 公共框架：所有菜单页面必须相同

`.app-shell`、`.sidebar`、`.topbar`、`.page-content` 是共享框架。不能新增 `.app-shell--usage`、`.app-shell--assistant` 等规则改变导航或外部布局。`.workspace--assistant` 只负责固定高度和滚动行为。Molly助手、CC Switch 与生图工作台是明确的沉浸式工具页例外：保留公共侧栏，但隐藏宿主顶部栏、账户提醒和页级错误条，让内嵌页面占满右侧工作区。灵动岛和 Skill 管理器共用 `.workspace--tool`：隐藏账户操作栏和账户提醒，保留共享内容边距，上方留白 20px；灵动岛在内容区滚动，Skill 由 iframe 内部滚动，不再用固定视口差值计算高度。

| 项目 | 规范 |
| --- | --- |
| 框架高度 | `100dvh`，最小窗口 960×640 |
| 侧栏宽度 | 224px；窗口宽度 ≤1180px 时 200px |
| 侧栏内边距 | 上 0px、左右 12px、下 16px |
| 标题栏 | Windows 高 32px，右侧自绘窗口控制；macOS 高 44px，左侧系统窗口控制，其右侧为菜单栏切换按钮；均不显示品牌图标或名称 |
| 一体式外框 | 标题栏与侧栏使用相同底色，移除标题栏下边线与侧栏右边线 |
| 右侧工作区 | 两个上角统一 16px 圆角，下角为直角；右侧保留 6px 外框，底部贴齐窗口 |
| 侧栏品牌栏 | 高 76px；MollyCloud 图标与英文品牌名和下方导航对齐，不显示中文品牌名 |
| 导航按钮 | 高 42px、圆角 14px、左右内边距 14px、图文间隔 12px |
| 导航按钮间隔 | 6px |
| 内容最大宽度 | 1440px |
| 页头和内容左右内边距 | 普通页面为 `clamp(20px, 2.2vw, 32px)`；沉浸式工具页为 0 |
| 账户操作栏 | 账户页面最小高度 72px，上下 12px；概览二级菜单置于左侧，刷新、更新、余额与账户入口置于右侧，同一行垂直居中；五个工具入口不显示账户栏 |
| 高度 ≤760px 的账户操作栏 | 保持 72px，与较高窗口一致 |
| 正文顶部间距 | 8px |
| 余额按钮 | 126×38px，胶囊形，账户页面显示钱包图标 |
| 用户按钮 | 高 38px；宽度 ≤1180px 时收为 38px 头像按钮 |

普通页面工作区预留稳定滚动条槽，避免有滚动条和无滚动条页面之间左右跳动。账户操作栏透明，与工作区背景融为一体。控制台不再重复显示当前菜单的大标题、问候语或介绍副标题；Skill 管理器各子页同样遵守此规则，去除页头文案后保留刷新、搜索、筛选和统计等功能操作。具体项目或 Agent 名称、目录、数量属于当前工作目标信息，可用 13px 工具栏文字显示；金额、订单、Token 分布等内容分组标签继续保留。不要通过全局隐藏 h1/h2 删除功能信息。Molly 聊天工具栏和 CC Switch、生图工作台原版内嵌内容保持各自边界。沉浸式工具页由聊天记录区或 iframe 内部负责滚动，内容填满共享工作区；所有页面都由工作区裁切上方圆角，使用相同的右侧外框留白，不向内嵌工具注入页面级修补样式。外框圆角和留白由 `--workspace-radius`、`--workspace-edge-inset` 控制。导航当前项提供 `aria-current="page"`，使用原生按钮保证 Enter/Space 操作。

普通页面的余额与用户入口保持等高，刷新图标与两者垂直居中，全部排在账户操作栏同一行并右对齐。更新提示出现在余额前方，不能挤出窗口。

顶级导航共七项：概览、API 密钥、CC Switch、Molly助手、灵动岛、生图工作台、Skill 管理器。“概览”选中后，右侧顶部显示“账户概览 / 订阅 / 用量 / 充值”二级菜单。四页保持父级概览选中，当前子页使用下划线、较深文字与 `aria-current="page"`。统计卡片跳转和紧凑侧栏均可访问子页。

不根据当前页面调整侧栏 padding、nav gap、导航高度、标题字体、余额按钮形状或用户按钮尺寸。响应式调整必须按窗口条件对所有页面同时生效。

Windows 控制台使用 32px 自绘标题栏。用户通过标题栏最左侧的“收起菜单栏”按钮切换紧凑模式；标题栏不显示 MollyCloud 图标或名称，并在右侧提供最小化、最大化/还原和关闭窗口控制。三枚图标的视觉中心保持在同一水平线上，最小化横线置于图标容器垂直中点。macOS 使用上文规定的 44px 原生窗口标题栏布局。关闭操作继续遵循控制台设置，不能绕过退出或最小化到托盘策略。

侧栏品牌栏只显示 MollyCloud 图标和英文“MollyCloud”，与下方导航内容水平对齐且不显示中文。紧凑模式在所有页面统一将侧栏收为 68px，保留品牌图标并隐藏品牌文字，同时只保留导航与设置图标。切换按钮不绘制常驻边框或底色，只有指针悬停时显示较深的浅绿色容器底色；键盘焦点继续使用公共焦点环。隐藏的导航文字必须继续作为原生按钮的可访问名称和悬浮提示。再次点击恢复标准侧栏，不能改变当前页面、嵌入页状态或控制台设置。

控制台“设置”入口固定在侧栏底部，使用与导航一致的 42px 高度、14px 圆角和图文间距，但不作为菜单页面或改变当前导航选中项。侧栏采用纵向 flex，底部区域以 `margin-top: auto` 定位；空间不足时只有导航列表可滚动，设置按钮保持可见。高度 ≤680px 时，所有页面统一将顶部项目栏收为 64px、侧栏下内边距收为 16px、设置上方留白收为 16px，为导航区提供独立滚动能力，导航高度和间距不变。

所有滚动区域统一使用细、低对比度滚动条，轨道保持稳定，仅鼠标悬停当前区域时显示滑块。移除上下三角箭头，保留滚轮、触控板、拖动和键盘滚动。样式入口为 `app/src/scrollbars.css`，内嵌工具仅导入滚动条规则。

主导航通过一个绿色背景滑块在选项间移动，带轻微拉伸与回弹（460ms）；文字和图标固定。概览二级菜单下划线平滑滑动（280ms），内容使用短淡出、淡入与轻微位移。所有动画尊重减少动态效果偏好。

概览二级菜单是全部横向功能菜单的标准。灵动岛、Skill 管理器以及后续新增功能必须复用 `.molly-subnav` 与 `navigationMotion.ts`：14px 文字、24px 间隔、透明底、选中加深加粗、3px 荧光绿下划线；下划线滑动 280ms，内容淡出 100ms、淡入与 8px 位移 240ms。菜单不绘制整条底部分割线或横向滚动条；保留选中下划线。不得重新实现页面专属胶囊菜单或独立过渡参数。窄屏只允许菜单自身横向滚动，隐藏轨道但保留触控板与键盘操作，选中项滚入可视范围；快速切换以最后一次选择为准，结束后清除内容 transform，减少动态效果时立即切换。

## 4. 圆角、边框与交互

基础间距为 4 / 8 / 16 / 24 / 32px；密集数据区域允许 12px 间隔。相邻、同职责控件使用一致间隔。

| 组件 | 圆角 / 尺寸 |
| --- | --- |
| 普通卡片、统计卡片、聊天外框 | 20px |
| 导航、标准按钮、输入框、提醒 | 14px |
| 小按钮、图标底板、小型状态区域 | 10px |
| 协议弹窗 | 24px |
| 状态标签、进度条 | 标签 6px；进度条胶囊圆角 |
| 小 / 中 / 大按钮 | 32 / 40 / 48px 高；登录主按钮保留 52px |
| 登录输入框、聊天输入框 | 56px 高 |
| 复选框 | 16px 方框，4px 圆角 |

边框只能由一层负责：

- 自定义外边框的 `NCard` 设置 `:bordered="false"`，账户 `NAlert` 同样关闭内建边框。
- 不叠加 Naive UI 内层边框、自定义 border 和彩色 inset shadow。
- 卡片内容区域的实际类名是 `.n-card-content`，不是 `.n-card__content`。优先用直接子元素选择器，避免修改嵌套卡片。
- 圆角容器内存在着色背景、伪元素或绝对定位层时，设置 `overflow: hidden`。键盘焦点画在外层控件上，不能一并遮掉。
- 不在圆角卡片顶部或左侧单独绘制彩色边，不用高亮模糊光晕掩盖边缘问题。
- 密钥使用自适应列表行；不增加竖向表格分割线或强制最小表格宽度。

普通卡片采用 `--shadow-card`，悬浮层采用 `--shadow-float`；公共工作区外侧采用低对比度 `--shadow-workspace`，在侧栏与工作区之间形成轻微层次，所有菜单页面一致。悬停以颜色或中性边框变化反馈，不整体移动导航、卡片和按钮。动画以 180ms 为基准，尊重 `prefers-reduced-motion`。

键盘焦点采用 2px 深绿 outline + 2px offset；输入和复选框通过统一 `--focus-ring` 表示焦点。加载时保留按钮尺寸；禁用时保留可辨认文字。

## 5. 登录和协议

复选框行按 24px 行高排版。16px 方框居中于标签的第一行，即上下各留 4px；禁止添加额外 `margin-top` 或用负外边距补偿。

选项区域以 8px 间隔排列“自动登录”和协议勾选行。标签换行时，方框仍与第一行居中，而不是和整个多行文本块居中。

协议链接使用继承字体和行高的行内原生按钮，不嵌入具有独立高度的 `NButton`。链接点击及键盘事件不应冒泡导致协议复选框被误选。必须验证：

1. 点击标签和按 Space 能切换复选框。
2. 用 Enter 打开协议时不自动勾选同意。
3. 协议默认勾选；用户可取消勾选。打开或关闭协议不改变当前选择，弹窗中的“我已阅读并同意”可重新勾选。
4. 表单变窄、错误提示出现时仍对齐，登录区可纵向滚动。

两步验证沿用相同表单宽度、输入框和主按钮规范。自动登录仍由用户选择；勾选后仅把刷新令牌保存到 Windows 凭据管理器，不保存密码。必须启用 keyring 的 `windows-native` 功能，并序列化控制台与桌宠的令牌刷新。不得用默认的内存后端冒充持久保存。

### 控制台设置弹层

点击侧栏底部“设置”打开居中悬浮选单。选单宽度为 `min(640px, 100vw - 64px)`，最大高度 `100dvh - 64px`，圆角 24px；头部与底部操作栏固定，内容超长时内部滚动。沿用共享字体、浅绿选择状态和按钮主题，不更换公共导航外观。

选单通过独立的 `#console-settings-layer` 呈现，遮罩对其后的控制台应用 9px 背景模糊、轻度降低饱和度及浅色透明蒙层。只模糊背景，选单正文保持清晰。打开时控制台设置 `inert`，焦点限制在选单内；关闭动画结束后焦点回到设置按钮，不能让键盘进入背后的 CC Switch iframe。

“关闭窗口”使用并列的 44px 紧凑原生单选项：“退出程序”与“最小化到托盘”，默认后者；图标、名称与单选框同一行，不使用大说明卡片。“系统启动”提供并列的 44px 紧凑开关行：“开机自启动”及其从属的“启动后最小化到托盘”；后者仅在自启动开启时可选，关闭自启动时自动关闭。系统启动设置读取 Windows 当前注册状态并在同一次保存操作中更新。保存前仅修改草稿；取消、Escape 和点击遮罩均丢弃草稿。右下角固定“取消”和“保存”，保存过程中禁用关闭与重复提交；读取或保存失败显示内联错误，不关闭选单、不把失败当作成功。系统自启动更新后若配置文件保存失败，应恢复保存前的系统状态。

桌面设置保存到 MollyCloud 应用数据目录中的 `console-settings.json`。原生后端在文件成功替换后才更新关闭行为；点击控制台关闭按钮时，托盘选项隐藏控制台并保留桌宠，退出选项结束整个应用并执行正常退出清理。带专用启动参数的 Windows 自启动才应用“启动后最小化”，用户手动启动始终唤起控制台。应用采用单实例运行；再次启动时不创建第二套控制台或桌宠，而是显示、还原并聚焦现有控制台。托盘菜单的明确退出始终退出，设置不修改账户登录策略。浏览器设计预览仅写入专用预览存储，不能修改桌面设置。

上述关闭偏好仅在已进入控制台后生效。启动加载、登录和两步验证界面点击关闭时，始终通过正常退出流程结束整个 MollyCloud（包括桌宠窗口与后台服务），不最小化到托盘。退出登录后再次适用此规则；已保存的关闭偏好保持不变。原生关闭判断使用控制台同步的当前界面状态，不能根据桌宠后台刷新的 Token 判断是否已进入控制台。

## 6. 页面内容和滚动

### 概览

八张紧凑统计卡片统一为白底、中性四边框、20px 圆角与柔和阴影，左侧 36px 图标，右侧标签、数值、辅助说明。宽窗口四列，≤1020px 两列。展示余额、密钥、今日请求、今日消费、今日 Token、累计 Token、活跃订阅及平均响应。下方展示真实累计 Token 构成和运行指标，不编造历史趋势；未返回的响应、RPM、TPM 显示“—”。

### 订阅与账户提醒

订阅条目按官网采用紧凑的两列卡片，实际内容宽度 ≤620px 时回落单列。保持共享字体与工作区背景，卡片使用供应商浅色四边框、品牌点和平台标签；头部展示套餐、倍率、状态、重置及自动续杯，正文展示到期信息和所有已配置的每日、每周、每月额度。进度条放在卡片内部，70% / 90% 分别使用警示色 / 错误色；到期文案标注今天、明天或剩余天数。

重置沿用官网扣费确认文案，确认后调用 `/subscriptions/:id/reset`，以服务端返回的新订阅 ID、额度和期限替换旧条目并刷新账户余额。自动续杯沿用官网确认、不再提醒及余额不足文案，通过 `/subscriptions/:id/auto-renew` 更新；开启后由服务端在额度耗尽或到期时扣费续杯。过期订阅不能开启，已开启的过期订阅仍可关闭。弹层复用公共设置容器和焦点规则，处理中禁用重复提交，失败保留状态；重置结果不明确时先刷新核对。详情从完整 `/subscriptions` 接口获取，可见且无遮挡时每 5 秒刷新，弹层与写操作期间暂停。

余额提醒和订阅提醒的左右边缘与正文卡片对齐，采用相同边框、圆角、图标容器与操作按钮；禁止单独增加左侧强调边。

### API 密钥

API 密钥导航使用用户提供的“项目密钥”SVG，外框保持 20px，视口留白使图形约 16px，与同类导航图标视觉大小一致；填充为 currentColor，与同类导航图标同步默认、选中及深浅色状态。分组名称提供可访问的切换按钮，点击展开可搜索下拉，选中即提交。展示供应商品牌色、分组说明、默认/专属倍率和当前项；上下键移动、Enter 选择、Escape 关闭。错误保留原分组与掩码，并在下拉内呈现；提交期间禁用重复选择。新增“创建密钥”入口，表单复用公共设置容器、字体与焦点规则，包含名称、供应商、分组及可选额度/IP/有效期。创建失败保留草稿，取消不创建，成功后显示掩码行。

每条密钥操作区提供“删除”按钮，沿用主题错误色与小按钮尺寸；二次确认复用共享设置弹层，默认焦点在取消，说明密钥失效与不可撤销。提交期间禁止重复操作，失败保留记录，成功移除后焦点回到创建入口。

公共顶部栏左侧先显示“创建密钥”，其右侧紧接约 300×32px 的 API 端点复制按钮，间距 12px；二者与右侧账户刷新、余额、头像水平居中对齐。显示完整地址及复制图标，复制后显示成功反馈，不占据正文卡片。“共 N 个密钥”保留在列表上方，列表使用独立白色圆角行，展示名称、状态、掩码密钥、复制、分组、实际累计 / 今日消费及 CC Switch 导入操作。通过容器查询按实际内容宽度排版：宽度大于 800px 时并列，≤800px 时身份信息与分组/额度分为上下两行，≤560px 时操作区另起一行。长名称换行，分组徽标和掩码密钥允许省略并提供完整名称提示，操作文字完整。禁止固定最小表格宽度或依靠隐藏溢出来掩盖内容，960×640 下同样不能出现横向滚动条。

点击“导入到内置 CC Switch”先打开居中悬浮菜单，可编辑供应商名称、选择 CC Switch 当前支持的全部 Agent（含 Claude Desktop），并设置默认模型。模型既可通过当前密钥从 MollyCloud 拉取后选择，也可手动输入；密钥本身不能暴露给前端。菜单底部固定“取消”和“导入”，取消与 Escape 均不写入。

导入入口始终显示“导入到内置 CC Switch”，成功后保持同一文案，不新增“再次导入”和“打开”按钮。导入只保存条目，不自动启用配置，同一密钥允许分别导入多个 Agent。未运行桌面后端的浏览器预览必须明确提示无法导入真实密钥，不模拟导入成功。

密钥条目采用中性细边框和清晰的信息层级，分别展示身份 / 分组 / 累计消费及今日消费 / 操作。消费来源为 `/usage/dashboard/api-keys-usage` 的 `total_actual_cost` 和 `today_actual_cost`，保留四位小数；无法读取时显示“—”。`quota_used / quota` 仅用于单独的配置额度与进度，不能当作累计实际消费。

### 用量

三张累计数据卡片分别展示请求、Token、实际消费，今日数据作次级说明。下方展示 Token 构成。数字不被卡片裁掉；窗口宽度 ≤1020px 时 Token 分类改为两列。

用量页采用中性卡片，语义色只用于图标和数值；取消大面积装饰光斑。

### 充值

“余额充值 / 订阅套餐 / 我的订单”复用共享选中滑块与内容过渡：滑块 460ms，内容先 100ms 淡出再 240ms 淡入并轻微位移。快速切换以最后选择为准，减少动态效果时即时切换；订单状态及独立支付窗口提示位于过渡内容之外，金额、套餐和支付会话状态由父组件保留。

充值位于概览二级菜单的用量之后，余额卡片、顶部余额及“前往充值”统一跳转到此页。保留公共账户操作栏、二级菜单和外框，不另加“充值与订阅”标题及介绍；内容由 Molly 原生金额、套餐与订单组件呈现，直接从充值分类和表单开始，不保留独立刷新按钮行。我的订单移除单独“查看”按钮，以整个订单行作为键盘可访问的详情入口，保留状态查询、取消和订单刷新操作。支付币种与 USD 余额分开标识；金额选项与套餐的“已选择”按钮使用完整荧光绿 `--color-lime`，悬停使用 `--color-lime-hover`；付款方式使用各自品牌色，中性卡片边框和字体遵循共享规范。

充值页使用普通工作区纵向滚动，最小窗口内可访问全部金额、套餐和订单操作。支付宝、微信支付的选中底色按用户参考图使用 `#00aeef` / `#24a038`，白色文字和所提供的品牌 SVG；未选中图标使用品牌色，付款方式名称后不再重复显示 CNY。金额选项、付款方式、可购买套餐和密钥分组按钮悬停时平滑改变底色或边框，不移动布局，禁用项不产生可点击的悬停反馈。可见但不可购买的套餐仍完整展示权益与价格并标注“不可购买”，禁用选择；在线支付整体关闭时也保留可见套餐信息。订单创建后自动打开独立、非模态的隔离支付窗口，右上角仅保留 X；控制台不设置 inert，切换页面与拖动窗口继续可用。扫码同时保留原生订单详情入口；关闭支付窗口不取消订单，取消订单需点击独立按钮。付款结果以服务端状态为准，完成后刷新余额/订阅。深浅主题同步，退出销毁临时支付视图。浏览器预览只使用标注的演示数据，不产生实际订单。权限与登录边界见 `docs/客户端充值与密钥分组.md`。

### Molly助手

助手页顶部采用与概览相同的“对话 / 设置”横向菜单，不显示“Molly”标题、齿轮按钮或顶部栏下方分割线；隐藏宿主账户栏与账户提醒。聊天外框无外边距、边框、圆角和阴影，占据工作区全部可用高度，`min-height: 0` 必须沿 flex/grid 高度链保留。卡片内部固定为：

```text
分类菜单与桌宠开关：72px，始终可见
聊天记录：minmax(0, 1fr)，唯一纵向滚动区域
输入区：自动高度，始终可见
```

消息气泡允许长文本换行。新增消息、低余额提醒、发送错误同时出现时，输入区不能落到窗口之外，外框不能随聊天记录增长。保留桌宠开关的可访问名称。

分类菜单左对齐，右侧使用紧凑的“开启或隐藏 / 开关”一行，不显示“桌宠”文本。菜单下划线和内容复用共享动画；减少动态效果时即时切换。对话和设置组件缓存，切换保留消息、输入文字及未保存草稿。

“设置”在当前工作区内显示，使用共享字段、内部滚动和固定“撤销修改 / 保存”底栏，不使用模态遮罩或背景 inert；保存过程中锁定分类和页面导航。`PetSettingsDialog.vue` 的内嵌模式复用原保存与模型管理流程。通过“模型 / 小助手设置”两个分类按钮切换内容。模型包含模型列表、PSD 导入、删除确认、大小、四边边界、两种边框，以及 PSD 自动行为和物理/外观参数。小助手设置包含模式开关、提供商、自定义端点、密钥、模型获取/选择、人格、问候间隔及对话历史清理。

在线语音放在“小助手设置”的现有滚动正文中，沿用开关、服务选择、密码输入、音量和试听控件；不改变公共导航、顶部栏、背景或桌宠透明窗口布局。默认服务 MiMo V2.5 TTS / 冰糖 / 流式，默认关闭，填写独立密钥后开启；风格提示内置且不展示编辑入口。自定义服务显示 API 端点、模型和音色 ID。试听使用草稿、不保存，产生服务用量；试听失败保留草稿。密钥不回填，改变服务或端点不能复用旧密钥，密钥与偏好使用 Windows 加密保存在应用私有目录。浏览器预览不调用语音服务，也不保存真实密钥。

已开启朗读时，助手先缓冲回复，等待首段音频实际开始播放时显示文字和共享对话记录；关闭朗读、合成失败或停止朗读时立即显示已生成文字，错误独立提示。朗读由桌宠窗口单独负责，控制台与桌宠共享回复不会重复播放；聊天输入区只增加紧凑状态与“停止朗读”入口，语音错误与聊天错误分开。新消息、关闭助手、清理历史和保存设置会停止旧播放；切换离开设置时停止试听。网络合成失败不影响已获得的文字回复，处理中的旧音频不能覆盖新播放。

内嵌设置字段为草稿；切换对话保留草稿，“撤销修改”恢复最近保存的快照，保存成功后保留设置页并显示反馈。模型切换、导入、删除和清空历史明确标注并立即执行；有未保存草稿时禁用这些操作，删除和清空需在弹层内确认。错误保留草稿，按钮和错误内容不得被长表单推出窗口。密钥输入默认空白，以“已保存，留空保持原密钥”表示已有配置；不回填已保存明文。更换提供商或端点不能继续使用旧服务的密钥。

订阅、API 密钥、用量页此前移除的重复介绍区和数量徽章不应恢复；当前页面通过选中的导航项表达，不增加页级标题或介绍。

### Petra 透明窗口

Petra/Live2D 窗口在控制台登录成功后才创建，登录及两步验证阶段不加载；注销时结束桌宠窗口，下次登录恢复本地模型与位置。控制台刷新不能覆盖用户手动隐藏桌宠的选择。Petra/Live2D 窗口具有独立的透明背景、拖动、穿透和悬浮布局。可以共享品牌色，但不能直接套用控制台的背景、最小宽度或滚动规则。

单击模型仅触发点击动画和互动记录，不自动展开上方天气/待办面板或下方聊天输入框。拖拽、右键菜单和明确的助手打开入口独立保留。

右键菜单最顶部固定“打开控制台”，用于显示、还原并聚焦现有控制台；其后隐藏“模型”“小助手设置”“开机自启”，继续隐藏“今日抽卡”和“对话记录”。模型与小助手配置入口统一放在 Molly助手齿轮弹层；设置通过带请求编号和响应确认的定向事件同步到桌宠，无需重启或强制显示隐藏中的桌宠。边框默认隐藏，仅在用户明确开启后显示，开发和生产构建行为一致。

余额入口位于模型头部左上侧，随模型缩放、位移和倒挂后的头部位置更新，不锚定 700px 窗口角落或整条裙摆的边界。常态为保留现有浅绿色表面的 40px 圆球，显示向下取整后的实际余额及 `$`，不补零、不封顶；如 9$、99$、100$、128$，较长金额适当缩小字号。圆边使用接近白色的带拖尾光点以 4.8 秒一周的速度逆时针环绕；拖尾必须位于光点前进方向的后方，即光点逆时针前进时拖尾沿顺时针方向延伸。减少动态效果偏好下停止旋转。

指针悬停或键盘聚焦时以常态圆球的右上角为稳定锚点，通过缩放和透明度过渡向左下展开为更大的圆球，收回时反向过渡。圆内使用标签、主金额、分隔线和次级 Token 数值的清晰层级，完整显示“余额 3.72$”与“今日消耗 128,400 token”。余额低于 1 时不显示圆球详情，常驻横向胶囊并显示“余额不足”。入口和展开圆球分别同步到原生鼠标命中区域，系统缩放只转换一次。靠屏幕边缘时钳制到可见区，底部放不下时允许向上展开。数据不可用时不能显示为 0；未登录时隐藏整个入口。

余额和今日 Token 使用同一账户的数据，每 60 秒及登录状态变化时刷新。相关实现位于 `app/src/petra/ui/BalancePill.ts`，真实头部锚点由 `PetView.getHeadBounds()` 提供。使用独立 Vite 服务时可设置 `MOLLY_UI_URL` 并运行 `node scripts/verify-balance-pill.mjs`；默认检查地址为 `http://127.0.0.1:24324`，截图位于 `artifacts/balance-pill/`。


任务运行或等待输入时，余额小球移动到模型头顶并扩展为自适应宽度胶囊：左侧 40px 圆球显示余额，右侧显示当前步骤，最大宽度 280px，超长单行省略，不显示任务数量角标。正文使用现有桌宠字体和 12px 字号。思考时优先显示 Codex 已落盘的公开摘要标题原文，缺失时使用“正在思考”；命令完成等步骤使用“运行了命令”等状态。不会显示摘要正文或原始推理。任务期间悬停、聚焦、点击都不展开下拉详情，移除面板之间的透明命中桥；进入任务时立即收起已打开的圆球详情。任务胶囊不显示外围光斑或边缘流光；余额圆球保留自身边缘动画。悬浮入口及详情不使用背景模糊，避免透明原生窗口中出现矩形底色。完成、失败或停止后恢复原位置的小圆球及 148px 圆形悬停效果，未读终态不能延续任务胶囊。位置切换使用 220ms 过渡，所有动画尊重减少动态效果偏好。
