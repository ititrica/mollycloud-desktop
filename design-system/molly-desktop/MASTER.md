# MollyCloud 桌面端设计规范

版本：2026-09-12 · 当前实施规范

适用范围：登录、两步验证、登录协议，以及概览、订阅、API 密钥、用量、Molly助手、CC Switch、生图工作台七个控制台页面。本文件取代早期紫粉色、科幻字体和深色方案，是后续界面修改的统一依据。页面细则只能补充内容布局，不能覆盖公共框架。CC Switch 和生图工作台的原版 UI 例外仅限各自独立内嵌内容区。

## 1. 设计目标与实现入口

界面使用浅色背景、深蓝文字、浅绿交互强调和克制的中性边框。数据优先，装饰服务于分组，页面切换时公共界面保持稳定。

| 职责 | 唯一维护入口 |
| --- | --- |
| 色彩、字体、圆角、阴影、公共尺寸 | `app/src/design-tokens.css` |
| Naive UI 组件主题与状态 | `app/src/theme.ts` |
| 公共框架、组件布局与响应式规则 | `app/src/styles.css` |
| 页面内容、语义与交互 | `app/src/App.vue` |
| CC Switch 内嵌容器与导航桥接 | `app/src/components/CcSwitchPanel.vue` |
| CC Switch 原版内容 UI 与宿主适配 | `vendor/cc-switch/frontend/src` |
| 生图工作台容器、存储与请求 | `app/src/components/ImageWorkbenchPanel.vue`、`app/src/imageWorkbench.ts`、`app/src-tauri/src/image_workbench.rs` |
| 生图工作台原版 UI 与适配 | `vendor/gpt-image-playground/src` |
| 主题接入 | `app/src/main.ts` |
| 页面回归检查 | `app/scripts/verify-design.mjs` |

组件主题读取 CSS token 并转为颜色字面值。Naive UI 会在 JavaScript 内计算派生颜色，不能把 `var(--color-…)` 直接传入需要颜色运算的主题字段。

关闭 Naive UI 默认 preflight，由公共 CSS 管理文档字体；不能仅设置 `common.fontFamily` 后假定正文已同步。开发和生产入口都要检查实际计算字体。

使用规则：

- 主按钮配深绿色文字，不能用白字叠在浅绿底上。辅助文字不能直接使用亮绿色。
- 选中导航通过浅绿色整块背景、深色文字和绿色图标表示，不依赖贴边色条。
- 普通卡片四边使用同一中性颜色。语义色放在图标、数字、状态标签或容器内部的有界区域。
- 余额和订阅到期提示属于同一种账户提醒，使用相同浅绿表面；错误提示使用错误色。
- 不为某个菜单页面重新定义背景色、导航字体或主题色。

### 字体与文字层级

正文统一使用 `--font-body`：Segoe UI Variable Text → Segoe UI → Microsoft YaHei UI → PingFang SC → sans-serif。中文和英文均保持无衬线外观，不加载独立的页面字体。

| 内容 | 规范 |
| --- | --- |
| 页面标题 | 32–42px，700，行高 1.15 |
| 页头说明 | 15px，行高 1.6，次要文字色 |
| 导航文字 | 16px，600 |
| 内容标题 | 普通分组 17–21px；用量构成和聊天工具栏 24–27px |
| 表单、表格、说明 | 13–16px，依信息密度选择 |
| 关键统计数字 | 22–40px，700 左右，等宽数字特性 |
| 密钥、API 端点、验证码 | `--font-mono`，Fira Code / Cascadia Mono / Consolas |

金额和统计值以正文字体配 `font-variant-numeric: tabular-nums` 为主。金额精度和币种由业务格式化函数控制，不能为排版修改金额含义。长消息允许换行；单行名称可以省略，但不能挤占操作按钮。

## 3. 公共框架：所有菜单页面必须相同

`.app-shell`、`.sidebar`、`.topbar`、`.page-content` 是共享框架。不能新增 `.app-shell--usage`、`.app-shell--assistant` 等规则改变导航或外部布局。`.workspace--assistant` 只负责固定高度和滚动行为。CC Switch 与生图工作台是明确的沉浸式工具页例外：保留公共侧栏，但隐藏宿主顶部栏、账户提醒和页级错误条，让内嵌页面占满右侧工作区。

| 项目 | 规范 |
| --- | --- |
| 框架高度 | `100dvh`，最小窗口 960×640 |
| 侧栏宽度 | `clamp(210px, 18.4vw, 266px)`；窗口宽度 ≤1180px 时 210px |
| 侧栏内边距 | 上 32px、左右 16px、下 24px |
| 品牌区 | 图标 42px、文字 20px；底部预留 36px |
| 导航按钮 | 高 56px、圆角 14px、左右内边距 14px、图文间隔 12px |
| 导航按钮间隔 | 10px |
| 内容最大宽度 | 1440px |
| 页头和内容左右内边距 | 普通页面为 `clamp(24px, 2.7vw, 40px)`；沉浸式工具页为 0 |
| 页头 | 普通页面最小高度 164px；上 36px、下 20px；沉浸式工具页不显示 |
| 高度 ≤760px 的页头 | 最小高度 134px；上 22px、下 12px |
| 正文顶部间距 | 12px |
| 余额按钮 | 178×64px，所有页面都显示钱包图标 |
| 用户按钮 | 高 64px；宽度 ≤1180px 时收为 64px 头像按钮 |

普通页面工作区预留稳定滚动条槽，避免有滚动条和无滚动条页面之间左右跳动。页头透明，与工作区背景融为一体。沉浸式工具页由 iframe 内部负责滚动，外部工作区不留边距。导航当前项提供 `aria-current="page"`，使用原生按钮保证 Enter/Space 操作。

不根据当前页面调整侧栏 padding、nav gap、导航高度、标题字体、余额按钮形状或用户按钮尺寸。响应式调整必须按窗口条件对所有页面同时生效。

控制台“设置”入口固定在侧栏底部，使用与导航一致的 56px 高度、14px 圆角和图文间距，但不作为菜单页面或改变当前导航选中项。侧栏采用纵向 flex，底部区域以 `margin-top: auto` 定位；空间不足时只有导航列表可滚动，设置按钮保持可见。高度 ≤680px 时，所有页面统一将侧栏上/下内边距收为 24/16px、品牌底部留白收为 24px、设置上方留白收为 16px，使七个入口适配最小窗口，导航高度和间距不变。

## 4. 圆角、边框与交互

基础间距为 4 / 8 / 16 / 24 / 32px；密集数据区域允许 12px 间隔。相邻、同职责控件使用一致间隔。

| 组件 | 圆角 / 尺寸 |
| --- | --- |
| 普通卡片、统计卡片、聊天外框 | 20px |
| 导航、标准按钮、输入框、提醒 | 14px |
| 小按钮、图标底板、小型状态区域 | 10px |
| 协议弹窗 | 24px |
| 状态标签、进度条 | 胶囊圆角 |
| 小 / 中 / 大按钮 | 32 / 44 / 52px 高 |
| 登录输入框、聊天输入框 | 56px 高 |
| 复选框 | 16px 方框，4px 圆角 |

边框只能由一层负责：

- 自定义外边框的 `NCard` 设置 `:bordered="false"`，账户 `NAlert` 同样关闭内建边框。
- 不叠加 Naive UI 内层边框、自定义 border 和彩色 inset shadow。
- 卡片内容区域的实际类名是 `.n-card-content`，不是 `.n-card__content`。优先用直接子元素选择器，避免修改嵌套卡片。
- 圆角容器内存在着色背景、伪元素或绝对定位层时，设置 `overflow: hidden`。键盘焦点画在外层控件上，不能一并遮掉。
- 不在圆角卡片顶部或左侧单独绘制彩色边，不用高亮模糊光晕掩盖边缘问题。
- API 表格只保留水平分隔线，禁止恢复竖向分割线。

普通卡片采用 `--shadow-card`，悬浮层采用 `--shadow-float`。悬停以颜色或中性边框变化反馈，不整体移动导航、卡片和按钮。动画以 180ms 为基准，尊重 `prefers-reduced-motion`。

键盘焦点采用 2px 深绿 outline + 2px offset；输入和复选框通过统一 `--focus-ring` 表示焦点。加载时保留按钮尺寸；禁用时保留可辨认文字。

## 5. 登录和协议

复选框行按 24px 行高排版。16px 方框居中于标签的第一行，即上下各留 4px；禁止添加额外 `margin-top` 或用负外边距补偿。

选项区域以 8px 间隔排列“自动登录”和协议勾选行。标签换行时，方框仍与第一行居中，而不是和整个多行文本块居中。

协议链接使用继承字体和行高的行内原生按钮，不嵌入具有独立高度的 `NButton`。链接点击及键盘事件不应冒泡导致协议复选框被误选。必须验证：

1. 点击标签和按 Space 能切换复选框。
2. 用 Enter 打开协议时不自动勾选同意。
3. 协议默认勾选；用户可取消勾选。打开或关闭协议不改变当前选择，弹窗中的“我已阅读并同意”可重新勾选。
4. 表单变窄、错误提示出现时仍对齐，登录区可纵向滚动。

两步验证沿用相同表单宽度、输入框和主按钮规范。自动登录仍由用户选择；勾选后仅把刷新令牌保存到 Windows 凭据管理器，不保存密码。必须启用 keyring 的 `windows-native` 功能，并序列化控制台与桌宠的令牌刷新。不得用默认的内存后端冒充持久保存。

### 控制台设置弹层

点击侧栏底部“设置”打开居中悬浮选单。选单宽度为 `min(560px, 100vw - 64px)`，最大高度 `100dvh - 64px`，圆角 24px；头部与底部操作栏固定，内容超长时内部滚动。沿用共享字体、浅绿选择状态和按钮主题，不更换公共导航外观。

选单通过独立的 `#console-settings-layer` 呈现，遮罩对其后的控制台应用 9px 背景模糊、轻度降低饱和度及浅色透明蒙层。只模糊背景，选单正文保持清晰。打开时控制台设置 `inert`，焦点限制在选单内；关闭动画结束后焦点回到设置按钮，不能让键盘进入背后的 CC Switch iframe。

“关闭窗口”使用一组原生单选框：“退出程序”与“最小化到托盘”，默认后者。“系统启动”提供独立的“开机自启动”开关，读取 Windows 当前注册状态并在同一次保存操作中更新。保存前仅修改草稿；取消、Escape 和点击遮罩均丢弃草稿。右下角固定“取消”和“保存”，保存过程中禁用关闭与重复提交；读取或保存失败显示内联错误，不关闭选单、不把失败当作成功。系统自启动更新后若配置文件保存失败，应恢复保存前的系统状态。

桌面设置保存到 MollyCloud 应用数据目录中的 `console-settings.json`。原生后端在文件成功替换后才更新关闭行为；点击控制台关闭按钮时，托盘选项隐藏控制台并保留桌宠，退出选项结束整个应用并执行正常退出清理。托盘菜单的明确退出始终退出，设置不修改账户登录策略。浏览器设计预览仅写入专用预览存储，不能修改桌面设置。

上述关闭偏好仅在已进入控制台后生效。启动加载、登录和两步验证界面点击关闭时，始终通过正常退出流程结束整个 MollyCloud（包括桌宠窗口与后台服务），不最小化到托盘。退出登录后再次适用此规则；已保存的关闭偏好保持不变。原生关闭判断使用控制台同步的当前界面状态，不能根据桌宠后台刷新的 Token 判断是否已进入控制台。

## 6. 页面内容和滚动

### 概览

四张统计卡片统一为白底和中性四边框，通过内部图标与数字区分分类。余额右侧展示累计消费，点击关系与数据含义保持一致。今日用量为独立分组，不与累计数据混淆。

### 订阅与账户提醒

订阅条目使用共享卡片外观，展示状态、计划、系统分配用量、到期信息。进度条放在卡片内部；剩余数字标注“剩余天数”，避免和日期字段混淆。

余额提醒和订阅提醒的左右边缘与正文卡片对齐，采用相同边框、圆角、图标容器与操作按钮；禁止单独增加左侧强调边。

### API 密钥

API 端点使用浅绿有界区域，列表使用共享白色卡片。表格最小内容宽度为 933px，以保留完整的“导入到内置 CC Switch”操作名称；空间不足时表格内部横向滚动，不扩宽工作区。密钥内容省略，复制和导入操作保留明确名称。状态标签沿用统一胶囊外观。

导入成功显示“已导入”和“打开”；“打开”进入内置 CC Switch 并定位对应供应商。导入只保存条目，不自动启用配置。未运行桌面后端的浏览器预览必须明确提示无法导入真实密钥，不模拟导入成功。

### 用量

三张累计数据卡片分别展示请求、Token、实际消费，今日数据作次级说明。下方展示 Token 构成。数字不被卡片裁掉；窗口宽度 ≤1020px 时 Token 分类改为两列。

允许浅色装饰存在于卡片内部并被圆角裁切，不能延伸为整页背景光斑或改变公共导航。

### Molly助手

聊天外框占据工作区剩余高度，`min-height: 0` 必须沿 flex/grid 高度链保留。卡片内部固定为：

```text
工具栏：自动高度，始终可见
聊天记录：minmax(0, 1fr)，唯一纵向滚动区域
输入区：自动高度，始终可见
```

消息气泡允许长文本换行。新增消息、低余额提醒、发送错误同时出现时，输入区不能落到窗口之外，外框不能随聊天记录增长。保留桌宠开关的可访问名称。

工具栏右侧的桌宠控制只显示“开启 / 隐藏”状态文字、开关，以及右侧 44×44px 齿轮按钮；不再添加“桌宠”标题、浅绿外框或状态卡片。齿轮具有“桌宠设置”可访问名称，点击打开 `PetSettingsDialog.vue`。

桌宠设置复用控制台设置的玻璃遮罩、560px 宽度、24px 圆角、固定页头与底部取消/保存栏、内部滚动和焦点限制；背景统一 `inert`，关闭后焦点返回齿轮。通过“模型 / 小助手设置”两个分类按钮切换内容。模型包含模型列表、PSD 导入、删除确认、大小、四边边界、两种边框，以及 PSD 自动行为和物理/外观参数。小助手设置包含模式开关、提供商、自定义端点、密钥、模型获取/选择、人格、问候间隔及对话历史清理。

普通字段为草稿，取消、Escape 或遮罩关闭时丢弃，保存成功后才关闭。模型切换、导入、删除和清空历史明确标注并立即执行；有未保存草稿时禁用这些操作，删除和清空需在弹层内确认。错误保留草稿，按钮和错误内容不得被长表单推出窗口。密钥输入默认空白，以“已保存，留空保持原密钥”表示已有配置；不回填已保存明文。更换提供商或端点不能继续使用旧服务的密钥。

订阅、API 密钥、用量页此前移除的重复介绍区和数量徽章不应恢复；公共页头已承担页面介绍。

### CC Switch

导航入口位于“Molly助手”下方。外部侧栏、导航间距和工作区背景沿用共享框架；进入 CC Switch 后隐藏宿主顶部栏、账户余额、用户按钮、账户提醒和页级错误条，内容从右侧工作区顶部到底部铺满，不保留宿主左右留白。

内容区使用独立的同源 iframe，保留 CC Switch 原版 React 菜单、组件、字体与主题。这是内容 UI 的明确例外；其 Tailwind 和全局样式只能在 iframe 内生效，不能注入 MollyCloud 文档，也不为该页覆盖公共 token。首次生成私有设置时默认开启“在主页面显示本地路由开关”，已有用户明确保存的关闭选择不被覆盖。

首次进入时加载，之后切换菜单保留已挂载的 iframe 和当前编辑状态。外框占据剩余工作区高度，flex 高度链保留 `min-height: 0`；列表和编辑表单在内嵌窗口中滚动，不能撑高外部窗口或出现外部横向滚动条。

加载状态不得遮挡初始化失败信息；失败时保留具体错误与“重新加载”入口。浏览器设计预览只使用明确的样例数据，不能冒充原生读写成功。宿主与子页面消息必须同时验证来源窗口和同源地址，导航只传工具类型及供应商 ID，不能传真实 API 密钥。

内置版管理本机工具实际使用的配置，恢复原版工具选择、MCP、Skills、会话、配置目录和数据管理入口。顶部说明“导入只保存供应商，点击启用后用于本机工具”；设置展示 Claude Code、Codex 和 Gemini 的实际目录。供应商库与备份保持 Molly 私有，管理器数据目录只读。窗口、托盘、自启动及更新仍由 MollyCloud 管理；完整行为、代理冲突处理与升级说明见 `docs/CCSwitch内置方案.md`。

### 生图工作台

入口位于 CC Switch 下方。公共侧栏和工作区背景不变；进入生图工作台后隐藏宿主页头、余额、用户按钮、账户提醒和页级错误条，让工作台占满右侧可用区域。密钥说明放在工作台设置中。

内容区复用 `.embedded-page`、`.embedded-panel`、`.embedded-frame` 的固定高度和内部滚动规则；沉浸式状态下移除宿主外框边框、圆角、阴影和内边距。原版 React UI、画廊、提示词编辑、参数和设置只在 iframe 内显示，不能注入宿主样式。

首次进入才加载，切换菜单保持 iframe 和正在运行的请求。退出登录卸载工作台并取消请求；按账户恢复配置和历史。首次创建配置时服务商默认为 `sub2api（异步）`，模型 ID 为 `gpt-image-2.5`，Base URL 为 `https://mollycloud.cn/v1`，密钥为空；设置内手动填写，离开输入框保存，另提供有成功/失败反馈的“保存密钥”。已有账户保存的服务商、模型和地址不被默认值覆盖。不能自动选择或注入控制台账户密钥，也不能在每次打开时覆盖用户修改的地址。

iframe 的 sandbox 不授予 `allow-same-origin` 或顶部导航；使用一次性 MessageChannel 连接，宿主校验当前子窗口并限定到配置、四张工作台数据表、图片网络请求与完成通知。子窗口没有账户存储和通用原生命令权限。不要沿用 CC Switch 的同源桥接策略。

内置版移除“安装为应用”和独立 PWA 更新流程，由 MollyCloud 一起更新。保留原项目名称、版权与关于信息；修改版来源说明随安装包分发。完整数据、网络限制和验证方法见 `docs/GPTImagePlayground集成方案.md`。

### Petra 透明窗口

Petra/Live2D 窗口具有独立的透明背景、拖动、穿透和悬浮布局。可以共享品牌色，但不能直接套用控制台的背景、最小宽度或滚动规则。

单击模型仅触发点击动画和互动记录，不自动展开上方天气/待办面板或下方聊天输入框。拖拽、右键菜单和明确的助手打开入口独立保留。

右键菜单隐藏“模型”“小助手设置”“开机自启”，继续隐藏“今日抽卡”和“对话记录”。模型与小助手配置入口统一放在 Molly助手齿轮弹层；设置通过带请求编号和响应确认的定向事件同步到桌宠，无需重启或强制显示隐藏中的桌宠。边框默认隐藏，仅在用户明确开启后显示，开发和生产构建行为一致。

余额胶囊紧贴模型头部左上沿，随模型缩放、位移和倒挂后的头部位置更新，不锚定 700px 窗口角落或整条裙摆的边界。胶囊高 30px，仅显示“余额 3.72$”形式的文字，不添加状态圆点或 US 前缀。

指针悬停或键盘聚焦时展开今日用量，完整显示“128,400 token”；胶囊到下拉区域的 6px 间隙也属于交互范围，避免移动鼠标时闪退。胶囊和下拉区域分别同步到原生鼠标命中区域，系统缩放只转换一次。靠屏幕边缘时钳制到可见区，底部放不下时向上展开。数据不可用时不能显示为 0；未登录时隐藏整个胶囊。

余额和今日 Token 使用同一账户的数据，每 60 秒及登录状态变化时刷新。相关实现位于 `app/src/petra/ui/BalancePill.ts`，真实头部锚点由 `PetView.getHeadBounds()` 提供。使用独立 Vite 服务时可设置 `MOLLY_UI_URL` 并运行 `node scripts/verify-balance-pill.mjs`；默认检查地址为 `http://127.0.0.1:24324`，截图位于 `artifacts/balance-pill/`。
