# MollyCloud 界面一致性审查

日期：2026-09-12。采用 `saas-dashboard` 标准，范围为登录、两步验证、协议弹窗和全部五个控制台页面。结论：公共框架已统一，用户指出的对齐和边缘叠色问题已修复。

## 主要发现与处理

| 原问题 | 状态 | 验证依据 |
| --- | --- | --- |
| 登录复选框有额外顶部偏移，协议链接具有不同文字高度 | 已修复 | 单行及强制换行时，方框中心与首行中心偏差均为 0px |
| 导航选中项贴边彩色阴影，卡片彩色顶边与圆角不协调 | 已修复 | 当前导航无 inset shadow/左边框；统计卡片四边均为中性边框 |
| 余额提醒同时存在自定义边框和组件内层边框；订阅提醒另加左边框 | 已修复 | 账户提醒仅有单层、同色四边框，内容由圆角容器裁切 |
| 用量、助手单独覆盖侧栏、背景、间距、字体和页头 | 已修复 | 五个页面依次切换后，公共框架计算样式和位置一致 |
| Naive UI preflight 覆盖全局字体 | 已修复 | 开发与生产入口的实际字体均使用项目字体栈 |
| 旧设计文档仍描述紫粉色、科幻字体和深色界面 | 已替换 | `MASTER.md` 现记录当前实施规则，根目录 `AGENTS.md` 指向该文档 |

### 框架与边缘

公共样式已移除按页面重写导航的规则。高亮只进入图标、文本或有界内部区域，普通卡片不再通过彩色顶边区分类型。账户提醒的边框由外层独立负责。

### 表单与状态

复选框采用 16px 方框与 24px 标签行高，协议链接继承行内文字尺寸。Space 可切换自动登录，Enter 可打开协议且不误选同意。错误提示和空状态遵循相同主题。

### 后续维护

新增页面直接复用公共框架。调整颜色和尺寸先修改 token/组件主题，再查看所有页面截图；不要通过更高优先级页面选择器修补公共样式。真正需要调整公共框架时，同步更新 `MASTER.md`。

## 验证记录

- 窗口：960×640、1180×760、1440×900。
- 页面：登录、两步验证、协议，以及概览、订阅、API 密钥、用量、Molly助手。
- 状态：余额不足、订阅即将到期、订阅/密钥空数据、聊天空数据、发送错误、长记录。
- 每个尺寸连续发送 14 次本地预览消息，产生 31 条记录；聊天外框与输入区保持固定，仅历史区域滚动。
- `npm run check:design` 输出页面截图和 `artifacts/design-review/report.json`；所有断言通过，无浏览器运行时异常。
- `npm test`：2 个测试文件、4 个测试通过。
- `npm run build`：类型检查和生产构建通过；构建仍提示较大的现有资源包，该项未在本次视觉修改中处理。
- 生产入口检查：使用构建后的页面和模拟的公开设置响应，确认主题颜色、字体、可用按钮文字对比及开发预览入口未进入生产流程。

本次未执行真实账户登录、Windows 凭据存储、原生 Tauri 窗口、系统缩放或屏幕阅读器验收。Petra 透明窗口保留独立布局，不因控制台统一样式而改变。
