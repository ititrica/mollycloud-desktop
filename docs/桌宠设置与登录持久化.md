# 桌宠设置与登录持久化

2026-09-12

Molly助手工具栏右侧提供桌宠开关和齿轮。齿轮弹层复用公共控制台设置外观，在控制台内完成 Petra 的模型管理、大小、边界、参数、小助手服务与密钥设置。模型和小助手设置不再出现在桌宠右键菜单，开机自启也隐藏；既有其他交互保留。

## 实现入口

- `app/src/components/PetSettingsDialog.vue`：表单草稿、模型管理、确认、失败反馈和保存/取消。
- `app/src/petSettings.ts`：共享参数定义、输入校验、定向请求与超时清理。
- `app/src/petra/main.ts`：串行处理设置请求，应用模型、保存本地偏好及同步聊天。
- `app/src-tauri/src/lib.rs`：小助手密钥继续由 Windows DPAPI 加密，写入用户应用数据目录下的 `api_key.bin`。对外状态只返回是否已配置，表单不回填旧明文。

普通设置点击保存才生效。模型切换/导入/删除以及对话清空立即生效且提供确认或反馈，有草稿时先保存或取消。模型加载失败回到原模型；密钥保存失败不提交新的本地偏好。自定义端点只允许 HTTPS 或本机 HTTP，更换端点或提供商后需重新填写密钥，旧服务密钥不会自动转发到新服务。

## 自动登录修复

原依赖 `keyring = "3"` 未启用原生后端，默认内存实现无法跨进程保存令牌。现在显式启用 `windows-native`，使用 Windows 凭据管理器的 `cn.mollycloud.client / mollycloud-session` 条目。仅勾选自动登录时保存刷新令牌，不保存密码；未勾选时保持内存会话。两步验证完成后使用相同策略。

控制台初始化与桌宠余额读取可能同时刷新令牌。`RuntimeState` 新增串行锁，登录接受、刷新与清除会话共用该锁，避免对同一轮换令牌并发刷新。启动恢复错误不再被前端静默吞掉。

旧版本未持久保存的令牌无法恢复；更新后需勾选自动登录并正常登录一次。协议按用户要求默认勾选，仍可取消。

## 安装资源边界

安装包只使用 `dist`、第三方声明和 `public/models`；不包含 Windows 凭据管理器、用户 AppData、WebView 配置、API 密钥文件或本地历史。构建前后运行 `app/scripts/check-package-inputs.mjs`，核对资源白名单，拒绝凭据文件、用户数据目录、符号链接及常见完整密钥字符串；错误仅输出文件名。

在同一 Windows 账户上重新安装时，应用可能读到该账户此前保存的本地密钥，这不代表密钥来自安装包。构建不清空用户的本机密钥；在另一台机器或新 Windows 账户首次安装时应为空。

## 验证入口

- `npm test`：包含设置输入边界、端点和安装资源检查。
- `cargo test --test session_persistence`：使用独立测试凭据条目验证跨进程保存、轮换与删除，以及控制台/桌宠仅刷新一次。测试不读取真实账户凭据。
- `npm run check:design`：登录、七个控制台页面及两种弹层，覆盖 960×640、1180×760、1440×900。
- `node scripts/verify-balance-pill.mjs`：独立浏览器配置下验证 Petra 原有交互、精简右键菜单、设置请求确认、保存失败回滚、密钥不进入本地偏好和状态响应。原生调用采用测试替身，不产生付费请求。
