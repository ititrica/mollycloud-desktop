# MollyCloud 桌面端更新发布

桌面版在每次启动时从 `https://desktop.veriolink.com/latest.json` 静默读取发布清单。只有清单中的 SemVer 版本高于本地版本时，控制台才会在账户余额左侧显示“软件可更新”；检查失败和没有新版本都不显示任何提示。

点击提示会用系统默认浏览器打开清单中的安装包链接。客户端只接受 `https://desktop.veriolink.com` 域名下的 `.exe` 文件，不会静默下载、安装或执行远端文件。

## 发布步骤

以 `0.1.2` 为例，先把 `app/package.json`、`app/src-tauri/Cargo.toml` 和 `app/src-tauri/tauri.conf.json` 的版本统一改为 `0.1.2`，再在 `app` 目录构建 NSIS 安装包：

```powershell
npm run tauri -- build
```

安装包应使用**不可变的版本文件名**，例如 `MollyCloud_0.1.2_x64-setup.exe`。上传安装包时设置长期缓存；`latest.json` 是唯一可变对象，必须禁止缓存。以下命令使用 `mollycloud-desktop` R2 bucket 和已绑定的 `desktop.veriolink.com` 自定义域：

```powershell
$installer = "src-tauri/target/release/bundle/nsis/MollyCloud_0.1.2_x64-setup.exe"
npx wrangler r2 object put "mollycloud-desktop/MollyCloud_0.1.2_x64-setup.exe" --file $installer --content-type "application/vnd.microsoft.portable-executable" --content-disposition "attachment; filename=MollyCloud_0.1.2_x64-setup.exe" --cache-control "public, max-age=31536000, immutable"
node scripts/create-release-manifest.mjs --version 0.1.2 --installer $installer --download-url "https://desktop.veriolink.com/MollyCloud_0.1.2_x64-setup.exe" --out "../output/release/latest.json" --notes "更新说明"
npx wrangler r2 object put "mollycloud-desktop/latest.json" --file "../output/release/latest.json" --content-type "application/json; charset=utf-8" --cache-control "no-store, max-age=0"
```

R2 使用对象的 `Cache-Control` 元数据控制响应缓存。发布前不要覆盖旧版安装包；只覆盖 `latest.json`。上传后在无登录状态下确认：

```powershell
curl.exe --fail --show-error "https://desktop.veriolink.com/latest.json"
curl.exe --fail --head "https://desktop.veriolink.com/MollyCloud_0.1.2_x64-setup.exe"
```

清单的最小格式如下。`sha256` 由生成脚本写入，便于在发布记录中核验安装包；当前客户端不自动执行安装，因此不会以清单哈希代替 Windows 代码签名。

```json
{
  "version": "0.1.2",
  "downloadUrl": "https://desktop.veriolink.com/MollyCloud_0.1.2_x64-setup.exe",
  "publishedAt": "2026-09-13T00:00:00.000Z",
  "sha256": "<installer SHA-256>",
  "notes": "更新说明"
}
```

## 回归检查

1. 本地版本等于或高于清单版本：余额左侧没有更新提示。
2. 清单版本更高且下载地址为发布域名上的 `.exe`：显示提示，点击能在系统浏览器打开下载。
3. 清单 URL、JSON 或网络异常：登录和控制台正常使用，不显示错误条或更新提示。
4. 清单包含其他域名或非 `.exe` 地址：客户端拒绝该清单，不提供下载入口。
