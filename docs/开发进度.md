# Molly Desktop 开发进度

更新时间：2026-09-11

## 已完成

- Tauri 2 + Vue 3 + TypeScript 桌面工程初始化。
- 主控制台和透明 Live2D 桌宠双窗口。
- Molly 模型、纹理、物理与 Idle/Blink/Nod/Shake 动作导入及 SHA-256 清单。
- MollyCloud 生产服务健康检查与公开设置读取。
- 邮箱密码登录、TOTP 分支、Refresh Token 轮换与登出。
- Access Token 仅驻留 Rust 内存，Refresh Token 使用 Windows 凭据管理器。
- 用户余额、订阅进度、API 密钥状态和用量统计读取。
- API Key 在 Rust 层掩码后再传给 WebView。
- 系统托盘、控制台关闭后隐藏、桌宠点击穿透与交互模式开关。
- 登录成功点头、登录失败摇头、四组动作手动测试。
- 浏览器视觉检查、TypeScript 构建、Rust 编译、Rust 单元测试及依赖安全审计。
- 锁定 Petra 0.2.3 提交 `9b4af14efc14696e4b249ecde1ad66008af502e0`，加入 MIT 第三方声明。
- 接入 Petra 风格的渲染/自主行为/助手分层；桌宠支持随机眨眼、动作调度和 AI/账户气泡。
- 新增 Molly AI 助手页：从用户普通 API 密钥获取模型列表，完整密钥只在 Rust 中使用。
- 新增余额、订阅、用量、密钥状态四个 AI 只读工具，工具输出采用字段白名单。
- 新增可配置低余额提醒、订阅临近到期提醒、12 小时去重和充值页跳转。
- 明确排除 shell、关机、文件删除、前台窗口读取与自动充值等高风险能力。
- 已生成 x64 MSI、NSIS 安装包和独立可执行文件；Petra 第三方声明已验证进入安装目录根部。

- 尚未使用真实测试账号执行登录后的线上契约对照；不能把用户密码写入自动化测试。

- AI 工具调用需要所选模型支持 OpenAI 兼容的 function calling；尚未使用真实账号做端到端计费与工具对照。
- Windows 安装包图标仍为开发占位图。
- 多显示器位置恢复、开机启动、完整用量趋势图和自动更新属于后续里程碑。
