# Molly 助手在线 TTS

更新日期：2026-10-03。在线语音与同步修复已收入 0.2.0 源码和安装包；历史 0.1.8 安装器不含这些功能。

## 配置与使用

入口：“Molly助手 → 设置 → 小助手设置 → 语音朗读”。默认服务为 MiMo，默认关闭。手动填写独立语音 API 密钥，使用“试听声音”验证后开启并保存。试听使用当前草稿，产生上游用量，不保存设置；“撤销修改”丢弃草稿，切换离开设置停止试听；对话 / 设置切换保留草稿。

MiMo 预置配置为 `https://api.xiaomimimo.com/v1`、`mimo-v2.5-tts`、`冰糖`、`stream:true`、24kHz PCM16LE 单声道。用户提供的完整角色 / 场景 / 指导提示词固定于 `app/src-tauri/src/tts.rs`，不提供编辑控件、不进入公开配置；只发送给所选 MiMo 合成服务。

自定义模式可填写 HTTPS Base URL（如 `https://api.example.com/v1`）、模型和音色 ID，采用 OpenAI `/audio/speech` 标准请求。当前自定义模式请求 WAV 后播放完整音频；MiMo 使用流式边接收边播放。仅回环本机服务允许 HTTP。端点不能包含账号、查询参数或片段，不跟随重定向转发凭据。

## 协议

MiMo 使用 `POST /chat/completions`，Bearer 鉴权。`messages[0]` 为 user 风格控制，`messages[1]` 为 assistant 待合成文本；`audio` 为 `{format:"pcm16",voice:"冰糖"}`。读取 SSE 中 `choices[0].delta.audio.data` 的 base64 分块，处理 CRLF、分割的事件与 UTF-8、空 choices、错误事件和终止标记，校验流是否完整。对话工具调用、命令、代码块和 URL 不被当成要朗读的正文。

自定义接口使用 `POST /audio/speech`，请求 `{model,input,voice,response_format:"wav"}`。支持 HTTPS 远程端点与明确的本机 HTTP 服务，响应须为音频。MiMo 与自定义请求均不自动重试，以免重复用量。

官方参考：[MiMo V2.5 语音合成](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)。本轮核对的正文和示例副本位于 `artifacts/tts-20261003/mimo-doc.txt`、`mimo-examples.txt`。

## 数据与生命周期

配置和独立语音密钥一起使用 Windows DPAPI 加密为应用私有目录中的 `tts-settings.bin`，原子替换保存。前端只读服务配置和“是否已配置密钥”，不读取明文密钥。更换服务 / 端点后需重新填写，不自动读取账户 API 密钥或复用对话密钥。没有本地语音模型、辅助 EXE、模型下载或上传凭据。

原生命令仅允许 `main` / `console` 窗口。试听仅由控制台使用草稿，不能把隐藏风格改成前端自定义内容。桌宠设置保存通过 `save_pet_credentials` 同时处理语音与对话密钥；语音保存失败恢复原有加密对话密钥，原设置写入失败由现有设置流程恢复草稿。

所有助手回复集中在 Petra `AssistantPanel`：普通聊天最终回复、主动问候、抽卡点评触发一次自动朗读。控制台同步会话，不再单独重复合成；控制台可停止朗读。新消息、助手关闭、清理历史、保存设置或页面销毁会停止旧请求与音频。取消按请求 ID 匹配，旧请求的迟到分块不影响新播放。流式 PCM 可跨分块拆开样本，播放器保持采样连续并释放已播放缓冲；音量作用于本次音频，不修改系统音量。

音频与文本处理受长度、分块、队列及超时限制，不落盘保存合成音频。认证失败、限流、连接或解码失败在设置或聊天中提示，已生成的聊天文字保留。
