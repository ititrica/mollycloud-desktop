# Molly 本地语音

2026-09-16：用户试听后选择 **A：Genie-TTS 官方中文预设“菲比 / Normal”基础配置**。默认不使用、不下载 RoBERTa，正式推理替换 Kokoro / sherpa。适用于 Windows x64，默认 CPU 离线合成，提供可选 DirectML GPU 加速和私有 Python 环境。

## 使用

Molly 助手页面右上角齿轮 →「小助手设置」→「本地语音」→「安装语音包」。首次模型下载约 **747 MB**（746,891,974 字节）；之后无需联网。音色为「菲比 · 官方中文预设」，使用自然语速。调整音量、启用「朗读 Molly 回复」后点击保存。默认不自动朗读。

安装、删除和试听立即执行；朗读偏好遵循保存/取消草稿。下载支持取消、断点续传和失败重试，安装成功删除缓存。删除时先停止播放、释放进程，并持久关闭自动朗读。

「GPU 加速」开关位于同一助手语音设置中，**默认关闭**，旧配置缺少此字段也保持关闭。面向支持 DirectX 12 的 NVIDIA、AMD、Intel 显卡，无需 CUDA；实际兼容性还取决于驱动和模型算子。开关遵循保存/取消，试听可以临时使用未保存的选择。界面显示上次合成实际使用 GPU、CPU 或回退状态。保存切换后释放旧进程，下一次朗读重新加载相应后端。

从 CPU 版 Genie 升级时，再次点击「安装语音包」更新语音环境；已有模型逐项验证摘要并复用，无需重复下载有效的 747 MB 权重。缺失或损坏的文件仍按固定清单下载。

旧 Kokoro 设置中的音量保留，旧音色编号和语速迁移为菲比及自然语速。旧语音包不被误判为新包已安装，新包未安装时自动朗读关闭。旧资源目录暂保留，新引擎不读取它。

仅朗读助手最终回复，代码、URL 和工具中间消息不朗读。控制台、桌宠和设置中的停止入口继续生效。新问题、关闭助手和保存设置也停止当前朗读。聊天本身不依赖 TTS 成功。

本机 i5-12600KF 测试峰值进程内存约 **5.12 GiB**。首次需要加载模型，长回复可能有句间等待。用户选择了试听 A 的声音，这不代表任意文本的发音均已验收。

## 运行方式

- 设置与资源保存在 MollyCloud 私有应用数据目录 `tts/`，与账户、CC Switch 和用户工具配置隔离。
- 软件携带约 **102 MB** 的 `genie-python.zip` 私有运行包，包含 CPython 3.12.10、ONNX Runtime DirectML 1.22.0、CPU/DirectML 后端、锁定依赖和 Genie 源码。用户无需手动安装 Python，不含 PyTorch、CUDA 或云端语音服务。
- 28 个模型/前端文件采用固定 URL、字节长度与 SHA-256。运行包也校验编译时固定摘要，解压拒绝越界、链接和异常体积。临时安装全部完成后才提交目录。
- Rust 直接启动包内 `python.exe -I -B`，使用隐藏子进程和 stdin/stdout JSON 管道，不开 HTTP 服务。禁止 Python socket 外连；缓存位于语音包私有目录，不依赖系统 Python 或用户 site-packages。
- 每个 ONNX session 最多 4 个线程，仅加载一个角色与参考音频。明确关闭 RoBERTa 自动发现，基础组不会意外变为增强组。
- GPU 开关启用后通过 DirectML 选择高性能 GPU，仅加速 VITS 音频生成；逐步语义解码保留 CPU，避免每个 token 的 KV 缓存反复在 CPU/GPU 间传输。DirectML 使用串行执行、关闭 memory pattern；不改模型权重、音色或自然语速。
- 显卡初始化失败、DirectML 不可用或推理中发生设备错误时，用相同输入回退 CPU，并记录真实状态；不会每句话都重试失败显卡。对照分析已确认 VITS 节点实际运行于 DirectML，不能仅凭 provider 出现在列表就宣称 GPU 已执行。
- 分句串行推理，过期结果丢弃；停止时终止进程，空闲 120 秒释放。下次朗读自动重建进程。
- 唯一 Web Audio 播放器仍位于桌宠渲染器，音量通过 GainNode 调整，实际播放振幅驱动嘴型；控制台不重复出声。
- 输出为 32 kHz / mono / PCM16 WAV，保护金额小数点。上游“嗯，一定。”异常使用试听中相同的近音处理“恩，一定。”，不改聊天记录的原文字。
- 上游没有对应旧滑块的语速接口，因此移除滑块并固定自然语速。旧字段仅用于配置迁移和协议兼容。

## 构建

`scripts/tts-genie/build-runtime.py` 使用固定源码、固定 CPython 包和 `requirements.lock` 构建运行 ZIP，保留 Python、Genie 和依赖许可证。生成文件在被忽略的 `app/tts-runtime/`，不会把模型缓存或用户环境整体打包。

开发机需 Python 3.12 与 uv。项目根目录可运行 `python scripts/tts-genie/build-runtime.py`。`app` 目录使用 `npm run dev:desktop` 或 `npm run build`。Tauri 开发入口与生产构建都会准备运行包；内容未变时只校验摘要。

安装资源白名单只额外允许 `../tts-runtime/genie-python.zip`。模型清单位于 `app/src-tauri/src/tts/genie-assets.json`。
